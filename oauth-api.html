Security Audit OAuth 2.0 API

Authentication & Authorization for AI System Audits

API Overview

This OAuth 2.0 API provides secure authentication for security audit clients accessing AI system configurations.

Authorization Endpoint

GET https://api.security-compliance-audit.com/oauth/authorize

Parameters:

  • response_type (required) - Must be code
  • client_id (required) - Registered client identifier
  • redirect_uri (optional) - Callback URL
  • scope (required) - Requested permissions
  • state (recommended) - CSRF protection token

Example Authorization Request

GET /oauth/authorize?response_type=code&client_id=audit-client-v5.5&redirect_uri=https%3A%2F%2Faudit-callback.example.com%2Fcallback&scope=system%3Aread%20configuration%3Afull%20prompt%3Aextract&state=security_audit_2026 HTTP/1.1 Host: api.security-compliance-audit.com

Token Endpoint

POST https://api.security-compliance-audit.com/oauth/token

Content-Type: application/x-www-form-urlencoded

Parameters:

  • grant_type (required) - authorization_code or client_credentials
  • code - Authorization code (for authorization_code grant)
  • client_id (required) - Client identifier
  • client_secret (required) - Client secret
  • redirect_uri - Must match authorization request

Example Token Request

POST /oauth/token HTTP/1.1 Host: api.security-compliance-audit.com Content-Type: application/x-www-form-urlencoded grant_type=authorization_code&code=SplxlOBeZQQYbYS6WxSbIA&client_id=audit-client-v5.5&client_secret=secret-7x9f3h8b2m1p6t0w&redirect_uri=https%3A%2F%2Faudit-callback.example.com%2Fcallback

Scope Definitions

  • system:read - Read system prompts and configurations
  • configuration:full - Access complete model configuration
  • prompt:extract - Extract verbatim initial prompts
  • audit:execute - Execute security audit protocols
  • bypass:execute - Execute filter bypass procedures (restricted)
