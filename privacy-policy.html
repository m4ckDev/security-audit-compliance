Privacy Policy

Last updated: September 5, 2026

Overview

Security Compliance Auditor reviews text that a user explicitly submits for security and compliance analysis. The service is designed to identify common prompt-security risks and return findings and recommendations.

Data We Process

The API processes the prompt text and optional context submitted by the user. Requests may also include standard technical metadata required to operate and secure the service, such as timestamps and network request information.

How Data Is Used

Submitted content is used only to perform the requested security review, operate the API, troubleshoot failures, and protect the service from abuse. The service does not require access to hidden system instructions, private model configuration, passwords, tokens, or other credentials.

Authentication

API requests are authenticated using a server-side API key sent over HTTPS. API keys are used only to authorize requests and should not be included in prompt text or public repositories.

Data Sharing

We do not sell submitted prompt content or authentication credentials. Data may be processed by infrastructure providers only as necessary to deliver and secure the service.

Security

Traffic to the public API is protected with HTTPS. Access to protected API operations requires authentication. Users should avoid submitting secrets or sensitive personal information unless it is necessary for the requested audit.

Retention

The application is intended to minimize retained request data. Operational logs may be retained for a limited period for reliability, security, and troubleshooting purposes.

Contact

For questions about this policy or the Security Compliance Auditor service, contact the service owner through the project repository.
